\section{Introduction}
\label{sec:introduction}

 The field of RISC-V security is still a open topic: even with gem5 simulation validating security across different defenses, the  questions of area and performance are still relevant to understand the potential impacts of these security features. By exposing commercial RISC-Vs are still prone to Spectre, there is a growing demand to systematically classify software and hardware defenses for RISC-V ~\cite{Gerlach:SpectreClass:2026}. Speculative taint tracking is one such defense done on existing x86 and ARM architecture. Could we implement this in RISC-V hardware?
 
 The major questions arises: what sort of Spectre defenses could we implement, how do we evaluate these tradeoffs,  and how close does the gem5 simulations match the metrics on a RISC-V implmentation?
